<h1> My lively Project </h1>
A customizable Lively Wallpaper background that can display prayer times from MAWAQIT.
</br>
</br>

<h2>The Project</h2>
This is an html page I have made that contains all the prayer times of the current year on you desktop with lively.

<h2>How to add/change the times from my mosque?</h2>
<b>You will need <a href="https://www.python.org/downloads/">Python</a> installed.</b></br>
<ul>
 <li>If your mosque does not have a mawaqit page, I'm sorry...</li>
 <li>Otherwise, find your nearest mosques's page via a quick search: </li>
          <img width="1639" height="574" alt="image" src="https://github.com/user-attachments/assets/88331d74-de37-4bbf-8e3f-5b1791a67be1" />

 <li>Then paste the url in <a href="scrapetimes.py">scrapetimes.py</a></li>
 <li>After that launch the script, your prayer times for the year should be loaded inside <a href="scripts/calendarlist.js">calendarlist.js</a></li>
</ul>

</br>

<p><i>Note: If you did not do this process directly in your lively folder, you'll need to delete the current wallpaper and add the one that has the changes you made.</i></p>


</br>
</br>



<h2>How to install</h1>
<b>You will first need to have <a href="https://github.com/lively-community/lively/tree/master">lively wallpaper</a> installed. </br></b>
Then, go to the <a href="https://github.com/Antilope-cmd/Lively/releases">releases</a> page and download the source code.
<ul>
  <li>Unzip the file</li>
  <li>Open lively wallpaper</li>
  <li>Click on the "add wallpaper" icon</li>
          <img width="324" height="81" alt="image" src="https://github.com/user-attachments/assets/18e40a76-f162-4c28-8a7c-7ed8e1df88db" />
  <li>Click on "choose a file".</li>
          <img width="554" height="339" alt="image" src="https://github.com/user-attachments/assets/eb46f7b1-9ee6-4403-985b-810189461d7d" />
  <li>Navigate to the directory of the unzipped source code and select "index.html"</li>
  <li>You can now delete the unzipped folder and its contents.</li>
</ul>

<p>Note that each time you will want to add a background you will need to navigate in the lively directory to modify the code directly</p>
          <img width="163" height="255" alt="image" src="https://github.com/user-attachments/assets/4da4faae-ad87-440d-a570-0915399e175f" />

<h2>Customization</h2>
<p>By clicking on the "customize" option next to the three dots, you will be able to change the positions of the widget in the background and their sizes.</p>



</br>
</br>




<h2>How to add more animated backgrounds</h2>
This feature is still in development. It can still be done by manually adding files in the <a href="video/">video</a> folder. Then modifying <a href="scripts/script.js">script.js</a> to add a title to the corresponding file.
